# Automations

Each automation is one page: `pages/<id>/RECIPE.md`, relative to this skill's
folder. Find the one the person named in the table below, by its title or
its id, read that page, then follow it step by step with the Synthesis tools.
If two could fit, ask which one they meant before starting.

Every page says how far it goes. Advise reads and recommends. Prepare hands
back a file or a change list that a person applies. On a schedule repeats
only while this computer is on. Push live is never done yet: prepare the
change list and say plainly that nothing was changed in any account.
A page whose status is not ready says what is missing: do the parts you
can and name the rest.
